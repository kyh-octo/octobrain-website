무엇을 할 수 있나요?

이미지·애니메이션·아이콘·문서·음악·동영상을 탭별 작업 흐름으로 변환합니다. 목표 용량과 크기를 정해 여러 파일을 한 번에 처리할 수 있습니다.

주요 기능

  • 이미지·애니메이션·아이콘·문서·음악·동영상 변환
  • 애니메이션 FPS와 너비 직접 입력
  • 원본 대비 비율 조정과 목표 용량 자동 처리
  • 여러 파일 일괄 변환

활용 예

  • 여러 이미지와 영상을 한 번에 필요한 형식으로 변환
  • 애니메이션의 FPS와 너비를 조정해 공유용 파일 준비
  • 목표 용량에 맞춰 파일을 줄여 업로드 준비

설치와 외부 구성요소

설치 파일은 .NET 런타임을 별도로 설치할 필요 없는 자체 포함 방식입니다. 자체 소스는 MIT 라이선스로 배포하며, 동봉된 외부 구성요소에는 각각의 라이선스가 적용되고 고지는 설치 폴더에 포함됩니다. 설치 파일은 Microsoft Artifact Signing으로 서명되며 SmartScreen 표시는 파일 평판과 보안 정책에 따라 달라질 수 있습니다.
