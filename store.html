무료 프로그램 다운로드

직접 개발해 무료로 배포하는 Windows 유틸리티입니다. 부담 없이 내려받아 사용하세요.

OctoPlayer

v1.2.1

무료 미디어 플레이어

MP4 · MKV · MP3 · FLAC 등 대부분의 미디어 형식을 재생합니다. 자막 싱크 조절, A-B 구간 반복, 재생 속도·화면 비율 조절, 이어보기까지 갖춘 가볍고 빠른 데스크톱 플레이어입니다.

  • 미디어 재생
  • 자막 · 구간 반복
  • libVLC 엔진

Windows 10/11 · 64bit · 72MB

다운로드 (.exe) ↓ 릴리스 노트 ↗

OctoCapture

v1.5.1

화면 캡쳐 · 녹화 도구

드래그 영역 · 창 · 스크롤 캡쳐 등 6가지 캡쳐 모드와 모자이크 · 화살표 이미지 편집, MP4 · GIF · WebP 화면 녹화를 하나로 담았습니다. 전역 단축키로 어디서든 바로 캡쳐합니다.

  • 6가지 캡쳐 모드
  • 녹화 MP4 · GIF
  • 이미지 편집

Windows 10/11 · 64bit · 51MB

다운로드 (.exe) ↓ 릴리스 노트 ↗

OctoConverter

v1.0.2

범용 파일 변환기

이미지 · 애니메이션 · 아이콘 · 문서 · 음악 · 동영상을 탭으로 나눠 변환합니다. 목표 용량을 정하면 품질을 자동으로 맞추고, 여러 파일을 한 번에 일괄 변환합니다.

  • 이미지 · 영상 변환
  • 목표 용량 자동
  • 일괄 변환

Windows 10/11 · 64bit · 43MB

다운로드 (.exe) ↓ 릴리스 노트 ↗
설치 안내 · 지원 환경

위 유틸리티 3종은 무료이며 MIT 라이선스로 배포됩니다. .NET 런타임 설치가 필요 없는 자체 포함(self-contained) 설치 파일입니다. 서명되지 않은 설치 파일이라 Windows SmartScreen 경고가 표시될 수 있습니다 — [추가 정보] → [실행]을 선택하면 설치됩니다.
