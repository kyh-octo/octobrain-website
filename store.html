OctoPlayer

v1.3.1

무료 미디어 플레이어

MP4 · MKV · MP3 · FLAC 등 대부분의 미디어 형식을 재생합니다. 자막 싱크 조절, A-B 구간 반복, 재생 속도·화면 비율 조절, 이어보기까지 갖춘 가볍고 빠른 데스크톱 플레이어입니다.

  • 미디어 재생
  • 자막 · 구간 반복
  • libVLC 엔진

Windows 10/11 · 64bit · 약 75.2MB

다운로드 (.exe) ↓ 릴리스 노트 ↗

OctoCapture

v1.6.1

화면 캡쳐 · 녹화 도구

드래그 영역 · 창 · 스크롤 캡쳐 등 6가지 캡쳐 모드와 모자이크 · 화살표 이미지 편집, MP4 · GIF · WebP 화면 녹화를 하나로 담았습니다. 전역 단축키로 어디서든 바로 캡쳐합니다.

  • 6가지 캡쳐 모드
  • 녹화 MP4 · GIF
  • 이미지 편집

Windows 10/11 · 64bit · 약 53.8MB

OctoConverter

v1.2.1

범용 파일 변환기

이미지 · 애니메이션 · 아이콘 · 문서 · 음악 · 동영상을 탭으로 나눠 변환합니다. 애니메이션은 프레임률(fps)과 너비를 직접 입력하고 원본 대비 비율로 축소하며, 실제 결과가 목표 용량 미만일 때만 완료됩니다. 여러 파일을 한 번에 일괄 변환합니다.

  • 이미지 · 영상 변환
  • 목표 용량 자동
  • 일괄 변환

Windows 10/11 · 64bit · 약 45.6MB

설치 안내 · 지원 환경

위 무료 유틸리티 3종의 자체 소스는 MIT 라이선스로 배포됩니다. 동봉된 외부 구성요소에는 각각의 라이선스가 적용되며, 고지는 설치 폴더에 포함됩니다. .NET 런타임 설치가 필요 없는 자체 포함(self-contained) 설치 파일입니다. 설치 파일은 Microsoft Artifact Signing으로 서명되며 게시자는 옥토브레인입니다. Windows SmartScreen 표시는 파일 평판과 PC 보안 정책에 따라 달라질 수 있습니다.
