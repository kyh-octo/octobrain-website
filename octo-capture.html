화면을 빠르게 캡처하고 필요한 장면을 녹화하는 무료 Windows 도구

최신 버전 무료 다운로드 ↓프로그램 목록

프로그램 목록에서 최신 설치 파일과 릴리스 노트를 확인하세요.

무엇을 할 수 있나요?

필요한 화면을 영역·창·스크롤 단위로 캡처하고, 이미지에 바로 표시를 더하거나 화면 녹화를 시작할 수 있습니다. 전역 단축키로 작업 중에도 빠르게 실행합니다.

주요 기능

  • 드래그 영역·창·스크롤 등 6가지 캡처 모드
  • 모자이크·화살표를 포함한 이미지 편집
  • MP4·GIF·WebP 화면 녹화
  • 어디서든 실행하는 전역 단축키

활용 예

  • 스크롤이 긴 웹페이지를 한 장의 이미지로 저장
  • 프로그램 오류 화면에 모자이크와 화살표를 표시해 공유
  • 작업 과정을 짧은 MP4 또는 GIF로 기록

설치와 외부 구성요소

설치 파일은 .NET 런타임을 별도로 설치할 필요 없는 자체 포함 방식입니다. 자체 소스는 MIT 라이선스로 배포하며, 동봉된 외부 구성요소에는 각각의 라이선스가 적용되고 고지는 설치 폴더에 포함됩니다. 설치 파일은 Microsoft Artifact Signing으로 서명되며 SmartScreen 표시는 파일 평판과 보안 정책에 따라 달라질 수 있습니다.
