연결부터 검증까지 이어지는 도구

프로토콜 연결, 서버 동작 확인, 레지스터 값 분석을 하나의 데스크톱 작업 흐름에서 다룹니다.

01

Master 연결

장치에 연결해 코일과 레지스터를 읽고 씁니다. Poll 작업을 탭으로 구성하고 분할·도킹하거나 별도 창으로 분리할 수 있습니다.

TCP · UDP · RTU · ASCII
02

Server와 Windows 서비스

서버 기능으로 외부 Master 요청에 응답하고, 독립 실행형 Windows 서비스 호스트로 서버를 운영할 수 있습니다.

TCP · UDP · RTU · ASCII
03

내장 시뮬레이터

서버를 실행하고 시뮬레이션 데이터 테이블을 확인·편집합니다. 여러 데이터 보기 패널을 열어 비교할 수 있습니다.

TCP · UDP · RTU · ASCII
04

데이터 형식과 바이트 순서

기본 레지스터 값에 더해 정수·실수 등 고급 형식과 엔디안 설정으로 실제 데이터 표현을 해석합니다.

SIGNED · UNSIGNED · FLOAT · ENDIAN
05

차트와 기록

변화하는 값을 차트로 살펴보고 통신 데이터를 기록·내보내기하여 진단에 활용합니다.

CHART · LOG · CSV
06

반복 가능한 작업

레지스터 맵, 작업 공간, 자동화 API를 사용해 자주 수행하는 점검 흐름을 정리하고 연동합니다.

MAPS · WORKSPACE · AUTOMATION API

// FAQ

자주 묻는 질문

지금 다운로드하거나 구매할 수 있나요?

아직 불가능합니다. Octo Modbus는 출시 준비 중이며, 서명된 설치 파일과 결제·라이선스 발급 절차가 준비되면 이 페이지에서 안내합니다.

지원하는 연결 방식은 무엇인가요?

Master와 Server 기능은 Modbus TCP, UDP, RTU, ASCII를 지원합니다.

라이선스와 업데이트는 어떻게 제공되나요?

구매한 버전은 영구 사용할 수 있으며 1.x 업데이트는 무료입니다. 향후 메이저 버전 업데이트의 제공 여부와 조건은 별도로 안내합니다. 최초 활성화에는 온라인 연결이 필요하고, 활성화 후에는 오프라인 사용을 지원합니다. 구매와 발급 절차는 아직 공개되지 않았습니다.

라이선스를 다른 PC로 옮길 수 있나요?

기존 PC에서 라이선스를 비활성화한 뒤 새 PC에서 활성화하면 이전할 수 있습니다.

제품 지원은 어디로 문의하나요?

support@octo-brain.com으로 문의해 주세요.

PC를 여러 대에서 사용하려면 어떻게 하나요?

3·5·10PC 팩을 준비하고 있습니다. 팩에는 PC별 라이선스가 포함되며, 팩 가격은 위 표에서 확인할 수 있습니다.

실제 Modbus 장치에서 검증되었나요?

제품 기능과 프로토콜 구현에 대한 설명이며, 특정 제조사 장치나 현장 배선·어댑터에 대한 하드웨어 인증을 주장하지 않습니다. 실제 장비에서는 사용 환경에 맞는 별도 검증이 필요합니다.
