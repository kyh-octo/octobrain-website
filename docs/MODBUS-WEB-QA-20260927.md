## 정적 검사 결과

- 두 Modbus HTML의 `href`/`src` 로컬 파일 참조와 현재 페이지 프래그먼트 34건을 검사했습니다. 누락된 파일 또는 프래그먼트는 없습니다. 각 페이지의 공통 스타일시트, Modbus 스타일시트와 로고·파비콘 파일도 존재합니다.
- 각 페이지의 JSON-LD 1개를 JSON으로 파싱했습니다. 모두 유효합니다.
- 두 페이지의 canonical은 각 언어 페이지를 가리킵니다. 양쪽 hreflang의 `ko`, `en`, `x-default` 매핑이 일치하며, `ko`와 `en` 링크가 각각 상대 페이지 canonical에 대응합니다.
- `sitemap.xml`은 XML 파싱에 성공했고, 두 Modbus URL이 포함되어 있습니다.
- 한국어·영어 페이지의 영구 라이선스 팩 가격이 동일합니다: PC 1대 $25, 3대 $65, 5대 $99, 10대 $179 (세금 별도). 제품과 가격은 출시 준비 상태로 표시되며, 구매·결제·라이선스 발급은 아직 제공되지 않습니다.
- 양쪽 페이지가 `assets/css/modbus.css?v=20260927-2`를 참조합니다. `assets/css/modbus.css`에는 `max-width:360px`에서 division label을 숨기고 내비게이션 버튼의 좌우 패딩·글자 크기를 조정하는 규칙이 있습니다.
- `store.html`의 Modbus 링크는 한국어 페이지를 가리키고, 번역 스크립트의 영문·일문 링크는 영문 페이지를 가리킵니다. 구매/결제 및 라이선스 발급은 준비 중이라는 문구를 유지합니다.
